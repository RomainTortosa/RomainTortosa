## 🚀 Projets

### 📦 StockFlow

Application web auto-hébergée de **gestion de stock et d'inventaire**.

Objectif : savoir précisément :

* ce que l'on possède ;
* combien il en reste ;
* où chaque objet est stocké ;
* qui l'a déplacé ;
* quand le mouvement a eu lieu.

**Fonctionnalités principales**

`Inventaire` · `Emplacements` · `Mouvements` · `Historique` · `QR / Codes-barres`

---

### 🖨️ RT-Print3D Manager

Un poste de pilotage pour une activité d'impression 3D.

Il permet de centraliser :

* les imprimantes ;
* les filaments ;
* les profils d'impression ;
* les produits ;
* les coûts matière ;
* la consommation électrique ;
* les marges ;
* l'historique des impressions.

L'objectif est de connaître le **coût réel et la rentabilité de chaque pièce imprimée**.

`3D Printing` · `Management` · `Costs` · `Self-hosted`

---

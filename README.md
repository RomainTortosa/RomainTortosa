## 🧠 À propos

Je suis **Romain Tortosa**, passionné par l'informatique, le développement, les infrastructures et la création d'outils.

Je cherche surtout à construire des solutions qui répondent à un **besoin concret**.

Mon approche est simple :

> **Comprendre le problème → construire la solution → automatiser → améliorer.**

Je m'intéresse particulièrement au **self-hosting**, à l'open source, à l'automatisation et aux outils qui permettent de gagner du temps.

# 🏠 Self-hosting

Une partie importante de mon environnement repose sur le **self-hosting**.

```text
                 ┌──────────────┐
                 │    INTERNET  │
                 └──────┬───────┘
                        │
                 ┌──────▼───────┐
                 │    ROUTER    │
                 └──────┬───────┘
                        │
                 ┌──────▼───────┐
                 │    SWITCH    │
                 └──────┬───────┘
                        │
          ┌─────────────┼─────────────┐
          │             │             │
      ┌───▼───┐     ┌───▼───┐     ┌───▼───┐
      │ Docker│     │ Linux │     │  Pi   │
      └───────┘     └───────┘     └───────┘
          │             │             │
       Services      Monitoring    Automation
```

### Pourquoi ?

🔐 **Contrôle** des données
⚙️ **Automatisation**
🧩 **Personnalisation**
💰 **Maîtrise des coûts**
📚 **Apprentissage**

> **Comprendre son infrastructure, c'est aussi comprendre ses outils.**
